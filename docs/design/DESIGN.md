# DESIGN.md — Arthosrot

> **Purpose:** the durable visual decisions as BUILT — ground truth for anyone styling a surface.
> **Audience:** every design/UI session. **Rationale lives in** [brand/BRAND.md](brand/BRAND.md); component rules in [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md); a11y method in [ACCESSIBILITY.md](ACCESSIBILITY.md); the motion dependency in [../architecture/adr/ADR-012-motion-dependency.md](../architecture/adr/ADR-012-motion-dependency.md).

## The world

**The bright ledger.** A cool-neutral off-white canvas (`--bg`) with white cards (`--surface`) on large radii and soft ink-tinted shadows; one near-black **wallet card** (`.hero-card`) carries the portfolio value and the net-worth curve, dark in both themes; the **colour-block quartet** (coral/teal/amber/blue) names categories on stat tiles and chips; **liquid glass** makes the chrome. Recognizable with all content removed: light canvas + one dark card + coloured tile chips + glass bars. Dark theme: deep charcoal surfaces, same accent system.

Register: **Product UI, Operate** — design serves the task; energy lives in structure and motion, never in verdicts on the user's money.

## Type

- **Anek Latin** (Ek Type, OFL), variable `wght 100–800 · wdth 75–125`, self-hosted at `public/fonts/AnekLatin-var.woff2`, `font-display: swap`. Body = `var(--font-ui)`.
- **Hero numeral:** `.hero-value` at `--text-hero` 2.5rem, weight `--text-hero-wght` 700, tabular. The boldest thing on screen.
- Bengali renders **only** as outlined vector inside the brand SVGs — never live `<text>` (conjunct shaping; BRAND.md §7). `--font-bn` exists for future Bengali UI text.
- Numerals: `tabular-nums` via `.tabular`, verified present in the font.
- Scale 12→24px (`--text-xs`…`--text-xl`) plus `--text-hero`; Read register tokens (`--text-read`, `--measure`) exist but no Read surface is built yet.

## Color

Strategy: **Committed** — the hero owns the account's primary region; each pop colour owns a category; the canvas stays neutral so numbers stay ink.

- Tokens: `src/styles/tokens.css` (OKLCH, light + dark + `prefers-color-scheme` fallback + `[data-mode="live"]` overlays). Every load-bearing pair is machine-checked by `scripts/check-contrast.ts` (**50 pairs**, incl. on-hero, on-pop, and glass-fallback sets).
- **The colour laws** (BRAND.md §6, enforced in review):
  1. `--accent` and the `--pop-*` quartet never on a number.
  2. `--gain`/`--loss` never on a control — BUY is not green, SELL is not red.
  3. `--hero` is a surface, not an accent — it owns the account's primary region or is absent; **one hero card per screen**.
  4. Glass is chrome, never a data surface.
- Gain/loss colour is never the sole carrier: every signed value carries sign text (sr-only where the visual is an arrow).
- On the hero: text `--on-hero`, secondary `--hero-muted`, financial colour `--gain-on-hero`/`--loss-on-hero` (the canvas pairs fail there — measured), curve `--chart-line-on-hero`/`--chart-fill-on-hero`/`--chart-grid-on-hero`. Controls on the hero invert: `.hero-card .btn-primary` is on-hero/hero.
- Primary buttons are black pills: `--ink` on `--bg`. `--accent` is for links, selection, the focus ring, and the active nav pill.

## Motion policy

- **Library:** `motion` (v13.2.0) in the client/UI layer only, under a global `<MotionConfig reducedMotion="user">` (ADR-012). Never in core/server/worker.
- **Springs:** sheets (native `<dialog>` kept; the inner wrapper springs), tap feedback `whileTap={{ scale: 0.97 }}` on nav pills and primary buttons.
- **Entrances:** mount-only staggered `rise-in` on stat tiles and list rows — **never re-triggered by data**; a refreshed value does not move.
- **CSS keyframes** in globals.css: `rise-in` (entrance), `sheet-up` (dialog open), `shimmer` (skeleton), `pulse-in` (status-badge state change via `key={state}` remount).
- **Tokens:** `--dur-fast` 120ms, `--dur-base` 180ms, `--dur-slow` 320ms, `--ease-out`, `--ease-spring`.
- **No celebratory motion, ever** — no confetti, streaks, count-ups, or success flourishes on fills, gains, or the paper→live graduation. No fades between order states. `prefers-reduced-motion: reduce` → instant (MotionConfig + the CSS media query).

## Verification contract

Any styling change must keep green: `pnpm check:contrast` (50 pairs — never weaken pairs, extend them), the axe scans inside `pnpm test:e2e`, and both themes at 390px and 1360px, with `[data-mode="live"]` checked in both. The texture grain, the open corner of the mark, the bilingual lockup spacing, and the three mode signals are identity and safety — not available for "cleanup."
