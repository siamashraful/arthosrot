# Responsive behavior

> **Purpose:** how each major surface adapts structurally across breakpoints — the phone-first design system on phones, its app-shell extensions on wide screens; never a shrunken desktop.
> **Audience:** UI implementers/reviewers. **Belongs here:** the adaptation matrix. **Lives elsewhere:** tokens (DESIGN_SYSTEM.md), screen content (UX_PATTERNS.md), the as-built mapping (DESIGN.md).

Breakpoints (as built in `globals.css`, unchanged): `max-width: 767px` (phone) · `max-width: 1023px` (tablet) · `pointer: coarse` · `prefers-reduced-motion`. Touch targets ≥ 44px. Respect safe-area insets (tab bar, sheets, the pinned trade bar). `inputmode="decimal"` on numeric inputs. The design system's artboards are 393 × 852 with a 20px gutter; ≤767 is where the app renders the system as drawn.

| Surface                   | ≥ 1024                                                                            | 768–1023                                       | ≤ 767                                                                                                                                                               |
| ------------------------- | --------------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Shell                     | Fixed left sidebar (`.shell-nav`: surface column, hairline edge, lime indicator)  | Sidebar collapsed to icon rows                 | `.mobile-top-bar` (lockup + icon buttons) + the system's **TabBar** (`.bottom-nav`: 5 items, **84px incl. safe area**, raised surface, centre disc, lime indicator) |
| Mode ribbon               | Info-tint Banner strip above the shell, `--ribbon-h` 32px                         | Same                                           | Same — never hidden; black under `[data-mode="live"]`                                                                                                               |
| Dashboard                 | Hero card + tile row (Stocks bloom tile, Cash paper tile, insight cards) \| lists | Single column; tiles 2-up                      | Single column, hero first, `.ar-tile-row` horizontal scroll / `.ar-tile-grid` 2-up, then list rows                                                                  |
| Tables (positions/orders) | True `.data-table` (app extension): tabular numerals, right-aligned, sortable     | Same, fewer columns                            | `.data-table.collapsible` — each row becomes a two-line list row (symbol + qty / value + P&L), not horizontal scroll                                                |
| Ledger/activity           | `.ar-row` list grouped by day (`.ar-group-label`)                                 | Same                                           | Same                                                                                                                                                                |
| Instrument page           | Chart left ⅔, trade ticket docked right ⅓ (`.ticket-docked`)                      | Chart full width, Trade button opens the sheet | Same; pinned Trade bar (`.ticket-mobile`, raised, above the tab bar) opens the ticket as a **BottomSheet** (native `dialog.sheet`, safe-area aware)                 |
| Trading ticket            | Docked panel                                                                      | Bottom sheet                                   | Bottom sheet — identical fields/summary/confirm at all sizes                                                                                                        |
| Charts                    | Hero curve height clamp 200–320px; hover crosshair + readout                      | Same                                           | Period selector = `.ar-seg--pills`; tap-crosshair                                                                                                                   |
| Dialogs/confirmations     | Centred `dialog.sheet` styled as the system's **Dialog** (`--radius-hero`)        | Centred                                        | **BottomSheet** (`--radius-sheet` top corners, grabber, `sheet-up` over `--duration-base`)                                                                          |
| Omnisearch                | Cmd/Ctrl-K palette (post-MVP)                                                     | Same                                           | Full-screen search from the top-bar icon                                                                                                                            |

Rules: navigation is persistent (no hamburger-only navigation); trading actions remain fully usable on touch; the mode ribbon and freshness indicators appear at every breakpoint; floating chrome (tab bar, pinned bar, sheets, toasts) takes `--shadow-float` in light and a surface step in dark — nothing else casts a shadow; the dosage rule (one hero, at most two saturated bloom blocks in view) holds at every width; E2E runs both desktop and mobile viewport projects (playwright.config.ts) and the visual check is both themes at 390px and 1360px.
